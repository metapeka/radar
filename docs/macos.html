macOS

Основной риск на Mac — не «вирус», а выданные когда-то разрешения и автозагрузка, о которой вы забыли.

Механизмы

Механизм Где включить Что даёт Приоритет
FileVault Privacy & Security → FileVault Шифрование тома; без пароля данные не читаются P0
Gatekeeper Privacy & Security → Allow applications from Проверка подписи и нотаризации при первом запуске P0
SIP Включён по умолчанию, csrutil status Защита системных путей от подмены P0
XProtect Автоматически Сигнатуры известного вредоносного ПО P0 (фон)
TCC Privacy & Security → Privacy Явные разрешения на доступ к данным и вводу P0 (ревизия)
Lockdown Mode Privacy & Security → Lockdown Mode Сокращает поверхность атаки; ломает часть функций P1
Advanced Data Protection Apple Account → iCloud E2EE для бэкапа iCloud, включая бэкап WhatsApp P1
Application Firewall Network → Firewall Блокировка входящих, скрытый режим P1
Background Task Management Автоматически (macOS 26) Спрашивает разрешение на фоновые задачи P1

Разрешения, которые надо перечитать

TCC — главный механизм, и главный источник проблем. Пять разрешений фактически равны полному доступу:

  • Accessibility — управление другими приложениями, чтение ввода.
  • Full Disk Access — чтение почты, Messages, баз браузеров, бэкапов.
  • Screen Recording — запись экрана и системного аудио.
  • Input Monitoring — перехват нажатий.
  • Automation — управление другими приложениями через Apple Events.

Проверка: Privacy & Security → Privacy. Правило: если приложение не делает ничего, что требует этого разрешения, — выключить. «На всякий случай» здесь не работает.

Автозагрузка и постоянные механизмы

Место Что смотреть
System Settings → General → Login Items & Extensions «Open at Login» и «Allow in the Background»
~/Library/LaunchAgents/ Пользовательские агенты
/Library/LaunchAgents/, /Library/LaunchDaemons/ Системные агенты и демоны (root)
/System/Library/Launch* Только Apple; менять нельзя при SIP
crontab -l, /etc/periodic/* Задачи по расписанию
Privacy & Security → Profiles Профили конфигурации; если есть — разобраться, откуда
sfltool dumpbtm Полный статус фоновых задач

Расширения ядра и системные расширения — kmutil showloaded и раздел Extensions. На Apple silicon кекст-расширения почти вышли из употребления, и их наличие — повод для вопроса.

Мессенджеры на Mac

Приложение Где данные Чем защищать
Signal Desktop ~/Library/Application Support/Signal Шифрование диска; ключ в Keychain
Telegram Desktop ~/Library/Application Support/Telegram Desktop/tdata Локальный код-пароль + FileVault
WhatsApp Desktop Контейнер приложения в ~/Library/Containers FileVault; отдельного пароля приложения нет

Общее правило: при разблокированном Mac и разблокированном Keychain данные мессенджеров доступны любому процессу с нужными правами. Поэтому FileVault и блокировка экрана важнее, чем «пароль на приложение», которого у WhatsApp на Mac всё равно нет.

Пределы

  • Прошивка, iBoot и изменения ниже ядра программно не проверяются. Косвенный признак — attestation и настройки Secure Boot, но это подтверждение ожидаемого состояния, а не доказательство чистоты.
  • Стилер, уже отработавший под вашим пользователем, не оставляет надёжных следов: данные ушли, логов нет.
  • ClickFix («вставьте команду в Terminal») обходил Gatekeeper, потому что запуск шёл не через Finder. С macOS 26.4 появилась блокировка вставки подозрительных команд, но привычка важнее патча.
  • Антивирус не видит обфусцированный AppleScript и расширения браузера в памяти.
