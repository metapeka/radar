# WhatsApp security research — поверхность атаки и защита

Исследовательский отчёт: как на самом деле угоняют аккаунты и переписку в WhatsApp, где слабые места и что делать для защиты.

**Дата:** 20 ноября 2026
**Формат:** markdown, 94 источника, 8 линий исследования, 2 раунда

## Содержание отчёта

- Модель угроз: что закрывает E2EE, что видит сервер, что отдаётся правоохранителям
- Разбор всех громких «утечек»: NSO/Pegasus, «500 млн номеров», «3,5 млрд аккаунтов», Facebook 533 млн
- Шесть работающих векторов угона: код подтверждения, SIM/eSIM/SS7, QR и код привязки устройства, кража сессии WhatsApp Web, общий ПК, поддельные клиенты
- Zero-click и шпионское ПО: CVE-таблица 2019–2026, Paragon Graphite, Predator, рынок эксплойтов
- Ранжирование поверхности атаки по вероятности для обычного пользователя
- Чек-лист защиты: базовый, гигиена, высокий риск, что делать в первые 30 минут после угона
- Российская специфика: статистика ЦБ и МВД, схемы, eSIM, Fake Boss
- Разногласия, открытые вопросы и ограничения исследования

## Вики (GitHub Pages)

Многостраничная версия с навигацией и поиском: **https://metapeka.github.io/whatsapp-security-research/**

- `site/content/*.md` — исходники страниц
- `site/assets/` — стили и поиск
- `tools/build_site.py` — сборка (`python3 tools/build_site.py`)
- `docs/` — собранный сайт, публикуется из ветки `master`, папка `/docs`
- `GOAL.md` — зачем проект и когда страница считается готовой (для передачи другим агентам)
- `VISION.md` — долгосрочная картина и принципы
- `DESIGN.md` — правила оформления: токены, компоненты, доступность, бюджеты
- `RISK-MODEL.md` — как пункты распределяются по профилям риска

## Провенанс источников

- `provenance/README.md` — правила фиксации: публичный манифест с хешами, приватные снапшоты.
- `provenance/sources.json` — девять источников по MAX: URL, дата, статус, SHA-256.
- `python3 tools/snapshot.py` — снять источник; `python3 tools/verify_provenance.py` — проверить хеши.

## Автоматизация

- `.github/workflows/digest.yml` — по понедельникам собирает черновик сводки (CISA KEV + NVD) и открывает Issue.
- `tools/collect_digest.py` — локальный запуск: `python3 tools/collect_digest.py --out digest-draft.md`.
- GitHub отключает расписание после 60 дней без активности; ручной запуск — `workflow_dispatch`.

## Оговорки

Материал носит защитный характер: описываются классы атак, опубликованные инциденты, CVE и меры противодействия. Пошаговых инструкций по проведению атак документ не содержит.

Часть первичных источников (`whatsapp.com`, `faq.whatsapp.com`, `transparency.meta.com`) была недоступна на момент исследования; официальные формулировки приводятся по поисковым выдержкам и цитирующим материалам, что отмечено в тексте. Утверждения размечены по уровню уверенности: подтверждено независимо / один источник / оценка.
