# MAX

> Российский мессенджер-суперапп. Ключевое отличие от WhatsApp и Signal: сквозное шифрование официально не заявлено, а часть данных по политике передаётся по запросу госорганов.

Аудитория и цифры — заявление оператора, независимого аудита нет.

## Шифрование

Что важно понимать до разговора о приватности:

| Утверждение | Статус |
|---|---|
| «E2EE есть» | **Официально не заявлено**: в соглашении и политике слова «шифрование» нет |
| Транспортное шифрование TLS | Есть, это минимум для любого клиента |
| Signal/Axolotl/Matrix | Не найдены при статическом разборе APK (август 2025) |
| Звонки | WebRTC; в кастомной реализации находили отключённую проверку сертификата сервера (май 2026) |

Вывод: по состоянию на ноябрь 2026 MAX ближе к облачному мессенджеру без E2EE, чем к Signal. Для сравнения: в Telegram E2EE есть хотя бы в секретных чатах, здесь публично не заявлено вообще.

## Какие данные собираются

По политике конфиденциальности (редакция 25.09.2026):

- имя, номер телефона, внутренний ID;
- IP-адрес, ОС, браузер, **местоположение**, оператор связи;
- данные адресной книги;
- активность в интерфейсе (клики), cookies;
- данные ЕСИА при подтверждении аккаунта;
- данные ГИС для Цифрового ID (статус совершеннолетия, льготные категории).

Отдельно, и это главное:

- **Передача госорганам** прямо предусмотрена: «исполнительные и судебные органы… по официальному и законному требованию».
- **Автоматическое сканирование** сообщений фильтрами допускается соглашением (п. 5.5) — на спам и незаконный контент.
- Сроки хранения конкретных категорий не названы: «до достижения целей, а после — в течение срока, установленного законодательством».
- Трансграничная передача не осуществляется, хранение — в РФ.

Это не «утечка» и не «взлом». Это описанная модель обработки, с которой пользователь соглашается при регистрации.

## Телеметрия: два разных результата

Публичные исследования дают несовпадающую картину — и это важно показать честно.

| Исследование | Метод | Результат |
|---|---|---|
| Август 2025 | Статический разбор APK | Стандартный набор разрешений мессенджера; Firebase нет, есть Huawei HMS |
| Сентябрь 2025 | Пассивный анализ трафика 30 дней через AdGuard | Трекеров не выявлено |
| Май 2026 | Статический разбор APK | MyTracker SDK, отправка списка установленных приложений, фингерпринт устройства, скрытый SDK с отправкой IP и флага VPN, проверка доступности хостов Telegram/WhatsApp |

Разные методики и разные версии приложения. Пассивный анализ видит только то, что прошло через сеть и не зашифровано на уровне приложения; статический — только то, что не обфусцировано. Ни один из них не даёт полной картины.

Позиция компании (апрель 2026): классификация Cloudflare вызвана «неверной интерпретацией заголовков веб-аналитики», приложение проходит аудиты, работает bug bounty. По пунктам выводы исследования публично не опровергнуты.

**Как это читать:** относитесь к обоим результатам как к гипотезам с датой, а не как к приговору или оправданию. Проверить на своей версии можно методикой из [анализа приложений](app-analysis.html).

## Разрешения

Android-манифест (по публичному разбору): контакты (чтение и запись), камера, микрофон, точная геолокация (включая фоновую), доступ к медиа. Для мессенджера это ожидаемо, но каждое разрешение стоит проверить: геолокация в фоне нужна далеко не всегда.

iOS: отдельного публичного разбора разрешений не найдено.

## Почему это важно для вашей переписки

1. **Нет E2EE** — значит, содержимое технически доступно серверу, а не только участникам.
2. **Сканирование фильтрами** разрешено соглашением.
3. **Передача по запросу** описана прямо, без оговорок про «только по решению суда» в узком смысле.
4. **Установка на iOS вне App Store** (после удаления 04.06.2026) означает доверие стороннему сертификату или профилю — проверяйте источник установки.

Если переписка чувствительная, MAX — не тот канал. Если нужен именно он (работа, госуслуги, окружение), — минимизируйте то, что туда попадает.

## Чек-лист

### P0

- [ ] Отдельный номер для MAX, не совпадающий с банковским и основным.
- [ ] Двухфакторная защита на почте и Apple/Google-аккаунте, к которым привязан номер.
- [ ] Проверить разрешения: геолокация — «только при использовании» или выключить; контакты — по необходимости.
- [ ] Не отправлять в MAX коды, документы, фото документов, финансовые данные.
- [ ] Установка только из официального источника, указанного оператором; на iOS — проверить профиль/сертификат.

### P1

- [ ] Настройки приватности профиля: кто видит номер, фото, последнюю активность.
- [ ] Отключить автозагрузку медиа в мобильной сети.
- [ ] Скрыть превью уведомлений на экране блокировки (настройки ОС).
- [ ] Проверить список активных устройств/сеансов, если функция доступна.
- [ ] Отдельный профиль ОС или отдельное устройство, если MAX нужен только для работы.

### P2

- [ ] Периодически проверять, какие приложения имеют доступ к аккаунту через ЕСИА/Цифровой ID.
- [ ] Держать чувствительные обсуждения в канале с E2EE (Signal), а в MAX — только организационное.

## Открытые вопросы

- Есть ли E2EE в новых версиях: официальных заявлений нет, независимых подтверждений тоже.
- Точные сроки хранения сообщений и метаданных не раскрыты.
- Публичных CVE по MAX не найдено; заявленные уязвимости (в том числе ZipSlip с оценкой 7.0–9.8) независимо не подтверждены.
- Заявление об утечке 46 млн строк (октябрь 2025) официально опровергнуто; подтверждённой утечки не установлено.

## Что делать, если MAX обязателен

Это распространённая ситуация: сервис предустановлен, используется для рабочих чатов и уведомлений. Разумная стратегия:

1. Разделить контуры: MAX — для организационного, Signal — для чувствительного.
2. Не смешивать номера: рабочий MAX на отдельном номере.
3. Считать, что всё отправленное может быть прочитано не только адресатом.
4. Проверять, что именно приложение просит при обновлениях: новые разрешения — повод отказаться от обновления до выяснения.
