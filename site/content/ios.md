# iOS

> На iPhone почти нет «вирусного» вектора — зато есть кража кода-пароля, подглядывание и профили конфигурации. И есть жёсткая привязка защиты к версии iOS.

::: {.callout .warning}
Функции безопасности привязаны к версии системы, а не к модели. Один и тот же пункт меню может отсутствовать на старом устройстве — и это не ошибка, а граница поддержки. Сверяйтесь с таблицей ниже до того, как искать настройку.
:::

## Версии и возможности

Поддержка функций зависит не от модели, а от версии системы. Это первое, что надо проверить.

| Функция | С какой версии | На iOS 18.7.x | На iOS 16.7.x |
|---|---|---|---|
| Lockdown Mode | 16.0 | есть | есть |
| Advanced Data Protection (iCloud) | 16.2 | есть | есть |
| USB Restricted Mode | 11.4.1 | есть | есть |
| Stolen Device Protection | 17.3 | есть | **нет** |
| Apple Threat Notifications | 17.6+/18 | есть | не гарантируется |
| Background Security Improvements | 26.1 | **нет** | **нет** |

Важно про модели: **iOS 18 поддерживают iPhone XS, XS Max и XR и новее.** iPhone X (A11) на iOS 18 не обновляется — его последняя версия 16.7.16 (11 мая 2026). Если на устройстве «iPhone X» установилась 18.7.12, это XS/XR, а не X.

Актуальная ветка 18.7 на ноябрь 2026 — **18.7.12 (сборка 22H390, 9 ноября 2026)**: шесть CVE в Bluetooth, AirPlay, CoreUtils (две), MediaRemote и rapportd, включая спаривание Bluetooth без участия пользователя. Эксплуатации в дикой природе Apple не заявляла.

## Ключевые механизмы

| Механизм | Где | Что даёт | Приоритет |
|---|---|---|---|
| Код-пароль 6+ | Face ID и код-пароль | Базовая защита; 4 цифры — плохая идея | P0 |
| Stolen Device Protection | Face ID и код-пароль | Вне знакомых мест Face ID без запасного кода + часовой задержки | P0 (17.3+) |
| Advanced Data Protection | Apple Account → iCloud | E2EE для бэкапа, фото, заметок | P0 |
| Lockdown Mode | Конфиденциальность и безопасность | Режет поверхность атаки: вложения, сложный веб, профили | P1 |
| USB Restricted Mode | Автоматически | Через час блокировки порт не передаёт данные | P1 |
| Профили конфигурации | Основные → VPN и управление устройством | Должно быть пусто | P0 |
| Сертификаты | Основные → Об этом устройстве | Пользовательский корневой CA = MITM | P0 |

## Профили и сертификаты

Два места, где чаще всего прячется проблема:

- **Профиль конфигурации** может задавать VPN, Wi-Fi, сертификаты, ограничения и даже MDM. В личном устройстве его быть не должно. В Lockdown Mode новые профили не устанавливаются — это, помимо прочего, хороший индикатор.
- **Установленный корневой сертификат** с полным доверием позволяет перехватывать TLS в приложениях, которые доверяют системным CA. Мессенджеры с pinning обычно защищены, браузер — нет.

## Обнаружение компрометации

| Инструмент | Как работает | Ограничение |
|---|---|---|
| MVT (`mvt-ios`) | Анализ шифрованного бэкапа и sysdiagnose на известные индикаторы | Ловит только известные IOC |
| iVerify | On-device проверка логов и артефактов | Не доказывает отсутствие заражения |
| Apple Threat Notifications | Системное уведомление о mercenary-атаке | Приходит редко и не всем |

Порядок работы с MVT:

```
idevicebackup2 backup --full --udid <UDID> ./backup     # шифрованный бэкап
mvt-ios extract-key ./backup
mvt-ios decrypt-backup -p <пароль> ./backup ./decrypted
mvt-ios check-backup --iocs malware.stix2 ./decrypted
```

Без пароля на бэкап часть данных не попадёт в архив — для диагностики шифрованный бэкап обязателен.

**Ключевая оговорка:** отсутствие индикаторов не доказывает чистоту. Современные импланты чистят следы, а неперсистентные исчезают после перезагрузки. Обратное тоже верно: найденный индикатор ещё не приговор, нужна интерпретация.

## Чек-лист

### P0

- [ ] Код-пароль 6+ цифр (лучше буквенно-цифровой).
- [ ] Stolen Device Protection включён в режиме «Always» (iOS 17.3+).
- [ ] Advanced Data Protection включён, recovery key сохранён.
- [ ] Профили конфигурации: список пуст.
- [ ] Пользовательские корневые сертификаты: незнакомых нет.
- [ ] Автообновления iOS включены.
- [ ] E2EE-бэкап WhatsApp (см. [WhatsApp](whatsapp.html)).

### P1

- [ ] Lockdown Mode — для повышенного профиля риска.
- [ ] Превью уведомлений отключены для мессенджеров.
- [ ] Двухфакторная защита Apple Account, доверенные устройства проверены.
- [ ] Background Security Improvements включены (iOS 26.1+).
- [ ] Аналитика и Tracking отключены.

### P2

- [ ] Экранное время как ограничитель установки приложений.
- [ ] Отчёт о конфиденциальности приложений — просматривать раз в месяц.
- [ ] Скрытые приложения проверены.

## Мессенджеры на iOS

- **WhatsApp:** E2EE-бэкап в iCloud, «Связанные устройства», passkey, блокировка приложения.
- **Telegram:** passcode, облачный пароль, активные сеансы.
- **Signal:** Registration Lock, связанные устройства.

Связка, о которой забывают: **ADP защищает бэкап iCloud, но не отменяет E2EE-бэкап WhatsApp.** Это два разных слоя, и включать надо оба.

## Пределы

- Антивирус на iOS против mercenary-шпиона бесполезен: он не имеет доступа к тому уровню, где живёт имплант.
- Проверить загрузчик и прошивку программно нельзя; косвенно — attestation и отсутствие джейлбрейка.
- Если устройство было скомпрометировано целевой атакой, правильный ответ — новое устройство и перевыпуск аккаунтов, а не «почистить».
