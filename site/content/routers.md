# Роутер

> Роутер — единственное устройство, через которое проходит весь домашний трафик. Заводской пароль и удалённое управление — самые частые ошибки.

::: {.callout .warning}
Если админка роутера открыта из интернета, пароль подбирают автоматически. Проверьте это раньше, чем менять пароль от Wi-Fi.
:::
