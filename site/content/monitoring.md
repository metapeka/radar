# Мониторинг

> Без базовой линии любое изменение выглядит либо нормой, либо паникой. Снимаем «снимок здоровья» и сравниваем.

## Что такое базовая линия

Набор артефактов, снятых на заведомо чистой системе: список автозагрузки, расширения, сертификаты, слушающие порты, учётные записи, хеши критичных файлов. Дальше всё сводится к сравнению.

| Платформа | Что снять |
|---|---|
| macOS | Login Items, LaunchAgents/Daemons, профили, TCC-разрешения, расширения, `sfltool dumpbtm` |
| Windows | Autoruns (полный экспорт), задачи планировщика, службы, расширения браузеров, сертификаты |
| Linux | systemd units, XDG autostart, cron, `authorized_keys`, sudoers, `lsmod`, `dpkg --verify` |
| iOS | Список приложений, профили, сертификаты, доверенные устройства |
| Android | Список пакетов, администраторы, Accessibility, доступ к уведомлениям |

## Периодичность

| Событие | Что делать |
|---|---|
| Раз в квартал | Полная ревизия по чек-листу платформы |
| После крупного обновления ОС | Проверить, что защитные настройки не сбросились |
| После установки «полезной утилиты» | Проверить автозагрузку и разрешения |
| После инцидента | Полный цикл: сбор → анализ → переустановка при необходимости |

Разовая настройка без ревизии деградирует: обновления сбрасывают разрешения, новые приложения просят доступ, старые настройки устаревают.

## Хеш-базлайн без специальных средств

Дешёвый вариант для Linux и macOS:

```
find /etc ~/.config ~/.local/share -type f -exec sha256sum {} + 2>/dev/null | sort -k2 > baseline-$(date +%F).txt
sha256sum -c baseline-2026-11-21.txt --quiet
```

Это не заменяет AIDE или osquery, но даёт быстрый ответ «что изменилось» без установки агентов.

## Как отличить дрейф от компрометации

| Признак | Скорее дрейф | Скорее проблема |
|---|---|---|
| Новый автозапуск | Появился после установки приложения | Появился без установки |
| Подпись файла | Валидная, известный разработчик | Нет подписи или подпись отозвана |
| Сетевое соединение | К известному сервису | К неизвестному IP по расписанию |
| Разрешение | Выдано вами осознанно | Выдано «само» или после «обновления» |
| Время появления | Совпадает с апдейтом | Ночью, без ваших действий |

Правило: один признак — не вывод. Нужны два-три совпадающих, иначе это шум.

## Что мониторить не надо

- «Перегрев и разряд» как индикатор шпионского ПО: слишком много ложных срабатываний.
- Антивирусные логи как основной источник: они не видят стилеры в пользовательском профиле.
- Сетевой трафик вручную без базовой линии: без нормы аномалию не отличить.
